4 Questions Evaluated

Interviewer Prompt
"Suppose you have a custom hook wrapping a WebSocket connection for real-time telemetry. How do you prevent memory leaks and unnecessary reconnections when the consuming component re-renders?"
Candidate Answer

"I'd isolate the socket lifecycle inside a `useEffect` keyed exclusively to the socket URL endpoint rather than unstable props. In the hook cleanup callback, I'd trigger an explicit `socket.close()` to avoid dangling sockets on unmount."

useEffect(() => {
  const ws = new WebSocket(endpointUrl);
  ws.onmessage = (e) => setData(JSON.parse(e.data));
  return () => { ws.close(); };
}, [endpointUrl]);
Interviewer Adaptive Follow-up
"What happens if incoming messages arrive faster than React state updates can render? How do you mitigate frame drops?"
Candidate Follow-up Answer
"I'd buffer high-frequency telemetry into a `useRef` queue and throttle or batch the state flushes using `requestAnimationFrame` or React 18's `startTransition` to yield priority to critical interactive renders."
psychology AI Evaluator Diagnosis

Candidate demonstrated flawless intuition for the React synthetic event loop and concurrent rendering priorities. Accurately identified that `useRef` bypasses the render cycle for high-frequency buffering.

Interviewer Prompt
"Where should a single-page application store authentication tokens, and how do you handle silent token refresh cycles?"
Candidate Answer
"Typically I put the JWT in `localStorage` so it stays available when the user reloads tabs, and I create an Axios request interceptor that adds the Bearer auth header."
Interviewer Adaptive Follow-up
"If an attacker exploits a third-party npm package to inject a rogue script, what prevents them from reading the token from localStorage?"
Candidate Follow-up Answer
"Well, with localStorage nothing really blocks that script. We could encrypt the token string before writing it to localStorage or use session storage."
psychology AI Evaluator Diagnosis

Critical conceptual deficiency in browser client security. Client-side encryption key cannot be secured from XSS. The expected industry standard is storing the refresh token in an `HttpOnly`, `Secure`, `SameSite` cookie, retaining only short-lived access tokens in JS memory closure.

Interviewer Prompt
"In an analytics collection with 5 million documents, how do you construct an aggregation pipeline calculating monthly revenue by customer tier without triggering RAM limits?"
Candidate Answer
"First, place the `$match` stage early to leverage compound indexes on date ranges before running `$group`. Add `allowDiskUse: true` if intermediate memory exceeds the 100MB RAM cap."
Interviewer Adaptive Follow-up
"How does compound index field ordering influence the `$match` stage?"
Candidate Follow-up Answer
"Equality filters first, followed by sort orders, and range filters last—the ESR rule. This narrows scan candidate documents immediately."
psychology AI Evaluator Diagnosis

Strong familiarity with MongoDB query engine execution plans and indexing heuristics (Equality, Sort, Range).
